*
  Resolved: 2026-09-02T02:19:09-07:00. Persisted truncation of managed native
  Codex executables could leave package metadata internally consistent while
  the launcher terminated with a segmentation fault. Root cause: post-install
  smoke validation was not retained or repeated, inspection trusted metadata
  without validating executable-format extents, and generated launchers
  forwarded operator commands without a health gate. Resolution: added
  portable ELF64, Mach-O64/fat, and PE32+ declared-extent validation before
  execution, inspection, and self-test; added a launch-time health gate; and
  added exact-version context-preserving `--repair` guidance and regressions.
  Details: `closed/truncated-native-payload-not-detected.md`

*
  Resolved: 2026-07-10T04:12:04-07:00. Rocky Linux 10.2 transplant recovery
  could not bootstrap the developer environment or isolated Codex payload
  cleanly. Root cause: bootstrap mutated a user-owned detached pyenv checkout,
  provisioned an obsolete minimum runtime, trusted drifted standard venvs,
  shipped a non-executable compatibility wrapper, and collapsed venv symlinks
  during validation. Resolution: separated those ownership layers, aligned the
  runtime on Python 3.14.6, preserved assistant memory during repair, restored
  stable Codex 0.144.1, passed 164 tests plus real standard/dev/self-test/login
  checks, and removed the emergency root npm install.

*
  Resolved: 2026-06-02T12:10:22-07:00. Managed `npm install --prefix .codex-local`
  could wait indefinitely after resolving a Codex version and writing
  managed files. Root cause: managed npm subprocesses had no timeout,
  and package installs allowed npm's optional audit, funding,
  update-notifier, and progress behavior during the critical install
  path. Resolution: added timeout-aware command execution, a
  300-second default npm timeout with `--npm-timeout-seconds`,
  install-only npm suppression flags, default HTTP fetch and foreground
  script logging, and regression coverage.

*
  Resolved: 2026-04-19T14:57:30-07:00. Bare operation words such as
  `codex-wrangler update` were treated as positional project roots, then
  produced uncaught tracebacks when no matching directory existed. Root cause:
  configuration normalization raised `CodexWranglerError` before the CLI error
  handler was active. Resolution: catch configuration errors in the entrypoint
  and add missing-dash hints for nonexistent roots that match known long-form
  flags, while preserving real directories named `update`.

*
  Resolved: 2026-04-15T21:04:00-07:00. Reasonable-permissions launchers used
  `-a never -s workspace-write`, which blocked ACP workflows in sandboxes that
  require escalation for `.git` writes and network push operations. Root
  cause: the managed default optimized ordinary file edits by disabling
  approval requests entirely. Resolution: changed the managed default to
  `-a on-request -s workspace-write`, documented the ACP-capable contract, and
  added launcher/README tests for the new default.
