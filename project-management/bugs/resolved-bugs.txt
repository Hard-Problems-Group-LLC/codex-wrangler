*
  Resolved: 2026-04-19T14:57:30-07:00. Bare operation words such as
  `codex-wrangler update` were treated as positional project roots, then
  produced uncaught tracebacks when no matching directory existed. Root cause:
  configuration normalization raised `CodexWranglerError` before the CLI error
  handler was active. Resolution: catch configuration errors in the entrypoint
  and add missing-dash hints for nonexistent roots that match known long-form
  flags, while preserving real directories named `update`.

*
  Resolved: 2026-04-15T21:04:00-07:00. Reasonable-permissions launchers used
  `-a never -s workspace-write`, which blocked ACP workflows in sandboxes that
  require escalation for `.git` writes and network push operations. Root
  cause: the managed default optimized ordinary file edits by disabling
  approval requests entirely. Resolution: changed the managed default to
  `-a on-request -s workspace-write`, documented the ACP-capable contract, and
  added launcher/README tests for the new default.
